# tslflyCar

零依赖的 HTML5 Canvas 小游戏集合。所有页面都是**单文件、无构建、无后端**，直接用浏览器打开即可运行。

---

## ① 特斯拉 Roadster「倒挂坡道 + Kickflip」复刻 · `tesla-flip-sim.html`

按 2026 年得州 SpaceX 基地第二代 Roadster 发布会「kickflip」演示还原：白色 Roadster 沿 C 形倒挂坡道爬升 → 车顶悬停（风扇吸附约 2G）→ 冷气推进器托举腾空翻转 → 四轮平稳落地。

**打开即自动播放**，完整流程：

> ① 地面加速、切线滑入右侧 C 形环形坡道 → ② 沿环右侧爬升、越过顶端倒挂悬停（速度为零，风扇吸附约 2G）→ ③ 冷气推进器喷白色气流、腾空翻转 → ④ 四轮平稳落地。

### 可调参数（右侧三个滑块）
| 滑块 | 说明 |
|---|---|
| 腾空高度 | 控制翻转弧顶高度（低 / 标准 / 超高） |
| 空中翻转 | 半圈（180° 复位） / 半圈 + 1 整圈 / 半圈 + 2 整圈 |
| 推进器强度 | 冷气推进器推力（40%–140%） |

### 参数对标发布会视频
- 倒挂高度约 **21 米 / 68.6 FT**
- 俯仰角约 **170°**
- 下压力 **4699 KG**（悬停时 HUD 显示；爬坡随环道从 1855 渐增至 4699，腾空时约 1200）

## ② VOLT 赛车 · 街道赛 · `index.html`

无需安装依赖的 Canvas 街机赛车。驾驶自己的电动跑车，在封闭赛道上与 5 位对手竞速，率先跑完 3 圈。最佳圈速保存在浏览器本地。

### 操作
- `W` / `↑`：油门
- `S` / `↓`：刹车
- `A` `D` 或 `←` `→`：调整走线
- `空格`：手刹漂移

手机端使用屏幕下方的方向、刹车和油门按钮。

### 在线预览
- VOLT 赛车：<https://jdb156158.github.io/tslflyCar/>

## 本地运行

直接用浏览器打开对应 `.html` 文件即可，无需任何依赖或构建步骤。

```bash
# 例如
open tesla-flip-sim.html
open index.html
```

## 部署

通过 **GitHub Pages** 发布，源分支 `main`、根目录 `/`。仓库推送后站点自动更新。
